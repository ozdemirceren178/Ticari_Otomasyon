# 🏢 Commercial Automation System

A web-based commercial automation system developed using ASP.NET MVC and Microsoft SQL Server. The project provides a structured platform for managing customers, products, employees, and commercial operations.

## 🚀 Features
* Customer management
* Product management
* Employee management
* Department management
* Sales and commercial operation management
* Database-driven data management
* Comprehensive CRUD operations
* MVC-based application architecture

## 🛠️ Technologies
* **Backend:** C#, ASP.NET MVC, Entity Framework
* **Database:** Microsoft SQL Server
* **Frontend:** HTML5, CSS3, Bootstrap, JavaScript
* **IDE:** Visual Studio

## 🏗️ Architecture
The application follows the **Model-View-Controller (MVC)** architectural pattern:
* **Model:** Represents application data and database entities.
* **View:** Provides the user interface.
* **Controller:** Handles HTTP requests, application logic, and communication between Models and Views.

## 🗄️ Database
The project uses Microsoft SQL Server for persistent data storage and **Entity Framework** for database operations.
